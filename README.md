**Sentinel** is an ML-based Network Intrusion Detection / Cyberattack Classification system — currently in active development.

The project combines:

`Machine Learning` + `Computer Networks` + `Cybersecurity`

**Goal:** Analyze network traffic features and use machine learning classification to distinguish normal traffic from potentially malicious activity / attack categories.
